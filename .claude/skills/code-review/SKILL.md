## 코드 리뷰 수행

다음 기준으로 코드를 검토합니다.

### 검토 항목

1. **버그 및 논리 오류**: 잠재적 버그, 엣지 케이스 누락
2. **보안**: SQL 인젝션, XSS, 민감 정보 노출
3. **성능**: 불필요한 반복, N+1 쿼리, 메모리 누수
4. **코드 품질**: 함수 길이, 중복 코드, 명명 규칙

### 출력 형식

각 문제는 다음 형식으로 보고합니다.

- **심각도**: 높음/중간/낮음
- **위치**: 파일명과 줄 번호
- **문제**: 무엇이 잘못되었는지
- **개선안**: 어떻게 고칠 수 있는지
